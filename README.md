   # Misinformation Detection

   A machine-learning project that screens news text using TF-IDF and
   Multinomial Naive Bayes, with a Flask + HTML/CSS/JavaScript web interface.

   Authors: Amrith R, Aswin S

   ## Results (held-out test set)
   Accuracy 96.32% | Precision 95.65% | Recall 96.34% | F1 95.99%

   ## Run locally
   pip install -r requirements.txt
   python app.py
   Then open http://localhost:5000

   ## Dataset
   Fake.csv and True.csv are not included because of file size.

   ## Limitations
   This is a screening aid, not a fact-checker.
